I turn complex data problems into reproducible analyses and check whether models remain reliable on real observations. My doctoral and postdoctoral work combines statistical modelling, machine learning, calibration and numerical computing. I have built reusable analysis workflows, investigated performance discrepancies and explained findings in international teams. Starting with no TensorFlow knowledge, I adapted existing research code, added new models, verified the code using simulated data and brought the computation onto a shared GPU workstation.

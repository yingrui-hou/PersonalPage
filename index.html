Domain Adaptation for ML

CatBoostFive-Fold ValidationReweightingDecision Thresholds

Built a CatBoost selection workflow for the rare Bs → phi gamma signal, connecting simulation/data checks, feature selection and five-fold training/testing to a threshold chosen for expected measurement precision.

Task and individual contribution

The goal was to select a rare signal from combinatorial background for a physics measurement. I developed the selection and validation workflow. I used existing Monte Carlo signal samples with detector simulation and reconstruction consistent with the data; I did not develop the original simulation software for these samples, although I studied calorimeter-simulation code.

Data preparation and domain checks

  • Applied preselection to reduce combinatorial background, then used fitted-component sWeights to study signal distributions statistically in mixed data. This did not provide pure signal labels for individual data events.
  • Proposed features from the decay physics, detector performance and subdetector observables. Used a topologically similar control sample to investigate simulation/data discrepancies and trained a hep_ml gradient-boosting reweighter where needed.
  • Checked correlations between features and with the target observable, excluding strongly correlated candidates to reduce the risk of distorting the measurement.

Training and choosing an operating point

  • Trained with simulated signal in the signal region and real-data background away from that region. Used five folds to make use of limited signal and background statistics.
  • Examined feature importance and ROC/AUC, removed low-contribution features and tuned hyperparameters for the retained feature set. Compared training and test responses to diagnose overtraining.
  • Scanned a task-specific figure of merit using signal/background efficiencies and expected event statistics. Chose the operating point for expected statistical precision and applied it to real data.

Expected yields and sample roles

At each threshold, estimated the signal and combinatorial-background yields as S = S0 × effs and B = B0 × effb, where S0 and B0 came from fitting the preselected data. These estimates were cross-checked against luminosity and process-cross-section expectations.

Reweighting preceded classifier training. Each training round used five folds with separate training and testing partitions; early rounds selected features, followed by hyperparameter tuning with the feature set fixed. The final application sample was not used for classifier training or hyperparameter tuning.

The scanned criterion was FOM = S / sqrt(S + B). Efficiency estimates used the combined training and testing events after KS checks showed compatible train/test responses and performance. Final model assessment came from the five-fold validation results; no additional untouched labelled test sample was available. These checks support train/test compatibility, without establishing an independent final generalisation estimate.

Result and transferable method

The selected working point was applied to data. The displayed comparison shows background suppression, and the training/test response plot supports the validation study. The transferable contribution is an analysis workflow linking domain knowledge, sample mismatch, model complexity and the decision threshold to the final task objective.

Methods: control-sample checks, feature correlations, gradient-boosting reweighting, ROC/AUC and precision-oriented threshold scans

Impact: connected data quality, model selection and the operating threshold to the precision objective of a rare-signal measurement.

Sensor Simulation & Reconstruction

Signal ProcessingSimulation CalibrationDigital Twins

Built a simulation-and-measurement workflow to quantify how detector non-uniformity affects energy resolution, using beam-test data to constrain the model instead of assuming ideal sensor response.

Problem

The key question was how much detector non-uniformity would degrade the energy resolution of a calorimeter. A flat-response simulation was not sufficient, because the measured light-collection efficiency changed across the detector volume, while a full optical simulation would add major complexity and computational cost. At the prototype development stage, combining a simplified simulation with an effective light-collection efficiency map measured from test-beam data is the most practical way to evaluate resolution.

Workflow

  • Built the measurement-to-simulation chain around the beam-test setup, combining the first prototype response, beam-position tracking, and dedicated analysis code to recover position-dependent light-yield information.
  • Used the June 2024 test-beam analysis to turn beam-position-resolved measurements into an effective light-yield / uniformity map and then injected that map into the Geant4-based energy-deposition simulation so that effective detected energy could be computed event by event under realistic response assumptions.
  • Implemented detector geometry, stepping, and response logic in Geant4/C++ and used the resulting distributions to fit energy-resolution curves under both measured and idealised response maps.

Result

  • Turned a beam-test measurement into a usable simulation input rather than leaving it as a standalone detector study.
  • Showed explicitly that non-flat response maps worsen the reconstructed energy resolution relative to a flat-response reference, with a non-uniformity-driven constant term less than 1.0% in the detailed study, which strengthens confidence in simulation-informed design decisions.

Personal delivery: beam-test automation

Developed a Shell pipeline for beam-test acquisition, storage, quick calibration and initial quality checks, connecting detector readout, tracking and timing calibration. Participated in on-site setup and data taking; assisted subsequent fitting and measurement-effect corrections. The pipeline connected existing algorithms; this does not imply that I authored every algorithm.

The early Run 3 reconstruction chain needed validation before performance discrepancies hardened into accepted bias. The main challenge was to distinguish normal modelling differences from issues that were actually actionable at detector, calibration, or software level.

Workflow

  • Compared MC and data across trigger streams and offline selections to isolate where discrepancies entered the pipeline.

Simulation truth matching: from diagnosis to an integrated change

In simulated high-occupancy events, high-energy reconstructed photon candidates showed anomalous energy resolution. Comparing reconstructed energy, truth energy and matched particle identity traced the problem to incorrect associations, including matches to higher-energy parent particles.

I modified the algorithm to compare individual truth-particle energy deposits within the reconstructed photon cluster, normalised by the total truth-particle energy deposited in that cluster. The match selects the largest single-particle contributor.

I checked the revised matching across multiple simulated decay processes, inspecting signal-photon matched identities, true and reconstructed energies, and selected events’ truth-decay chains and particle energy deposits. Following reviewer feedback, I also revised legacy code to improve thread safety. The merge request was merged and the change used in subsequent Run 3 analyses and reconstruction-performance checks. This contribution concerns simulation truth association, separately from evaluating the clustering model on real data or training that model.

Pulse-Shape Discrimination for Energy Reconstruction

Pulse Shape DiscriminationDetector SimulationTime-Resolved Signal AnalysisResolution Optimisation

Built a PSD-oriented simulation and analysis workflow to extract shower composition from scintillation time profiles and use it to improve reconstructed energy.

Problem

The problem was to recover useful composition information from scintillation timing, instead of treating total light yield as a single undifferentiated signal. For the method to be credible, it also had to remain usable under realistic material behaviour, particle-dependent time constants, and the limited separation between EM-like and hadronic-like components.

Experimental comparison guiding material choice

The team tested ZnWO4 and BGO by measuring scintillation decay-time profiles across energy ranges and electromagnetic or hadronic excitation processes. The design criterion was how well the time profiles could distinguish these processes under the tested conditions.

The team chose ZnWO4 for further PSD studies. At low energies, the measured BGO profiles were too similar to the electromagnetic-excitation profiles to provide the desired separation. This experimental material comparison informed the subsequent modelling work; it is separate from the simulated reconstruction-resolution results below.

Engineers handled the measurement setup and particle-source operation. I participated in comparing the final time profiles, then used the measured timing parameters as simulation inputs, generated samples and checked whether the resulting temporal separation was sufficient to apply PSD. My contribution connected experimental measurements to a simulation feasibility check.

From curve screening to quantitative feasibility checks

First compared normalised time profiles to screen for excessive similarity. Using the measured parameters, simulated high-energy protons entering the calorimeter sensitive layer, their energy deposits and the resulting scintillation-light time profiles.

Fitted the complete light time profile with fixed templates to estimate photon counts from the different processes, before using the components for PSD energy reconstruction. When profiles were insufficiently separated, component counts could not be recovered accurately at this stage. Fit-result correlation matrices and bias distributions were used to assess the reliability of component recovery. These diagnostics connected the material choice to whether the proposed reconstruction method was usable.

Workflow

  • Generated e/p/pi simulation samples in two crystal-material candidates (ZnWO4 and BGO) over 1 to 20 GeV and first validated that the relevant correlation structure between deposited hadronic energy, EM fraction, and total energy remained stable across the energy range.
  • Extended the simulation with scintillation timing, updating time constants dynamically by particle type and dE/dx, then fitted the time distributions with EM-, hadronic-, and proton-like components instead of relying only on total signal amplitude.
  • Used the extracted fractions inside a correction workflow for reconstructed energy, then compared the resulting resolution before and after correction while checking which material choices stayed separable enough for PSD-based inference.

Result

  • Showed that the PSD-based correction improves deposited-energy resolution, with one representative rotation-based study reducing the resolution term by about a factor of 2.
  • Demonstrated that the time-profile fit can recover the dominant EM component with usable accuracy, for example F_em = 0.740 +/- 0.055 for a reference value of 0.738 in one validation study.
  • Identified a practical design constraint rather than just a positive result: one material candidate (BGO) did not separate proton-like and electron-like timing strongly enough for accurate EM-fraction extraction, while ZnWO4 retained more distinguishable time shapes and therefore offered a more credible PSD route.

Publications & Reports

  • [Internal report: PSD study update] summarizes the time-profile fitting, EM-fraction recovery, and resolution-improvement studies behind this PSD workflow.

Methods: particle-dependent timing models, component fitting, correlation-based correction

Impact: showed that PSD-derived shower fractions can improve reconstructed energy and help judge which detector materials remain usable for timing-based separation.

Built a bias-corrected time-series inference workflow for data affected by selection effects, detector resolution, and sample mismatch.

Problem

The core problem was to infer latent time-dependent behaviour from observations distorted by selection effects, finite resolution, and data-simulation mismatch. Without explicit correction, those effects would bias the inferred dynamics rather than just broaden the uncertainty.

Workflow

  • Modelled acceptance and resolution explicitly instead of absorbing reconstruction effects into a single nuisance term.
  • Estimated Run 1 and Run 2 corrections separately to avoid over-sharing assumptions across datasets with different operating conditions.
  • Matched signal and control samples through GB reweighting before building acceptance corrections, and implemented reusable fit components for mass, lifetime, efficiency, and resolution modelling.

Result

  • Converted a bias-sensitive time-series problem into a controlled inference workflow with dataset-specific corrections and auditable assumptions.
  • Propagated residual mismodelling as quantified uncertainty rather than hiding it inside nominal fit parameters, which made the method reusable across datasets and reviews.

Model Correction Workflow

Scientific SoftwareEvent FilteringSimulation CorrectionFramework Integration

Developed simulation-correction tooling that turns measured physics constraints into an event-level resampling workflow.

Problem

The simplified fast simulation was good enough for most kinematic behaviour, but it could not reproduce one paired-particle correlation effect needed downstream. A full first-principles simulation of the multi-body process was not practical, so measured constraints had to be folded back into the event distribution in an operational and auditable way rather than through ad hoc post-processing.

Workflow

  • Built a framework-integrated C++ package to correct inclusive fast-simulation samples event by event so that the missing correlation effect was restored.
  • Encoded correction factors from measured inputs into a filtering workflow that keeps or rejects events to match the corrected distribution.
  • Designed the package with headers, source files, job options, and framework integration points so the correction logic is reusable beyond a single analysis or software stack.

Result

  • Turned measured constraints into a reusable event-level correction package for improving simplified simulation realism.
  • Kept the event-level behaviour explicit and auditable: each event receives a correction factor and is accepted or rejected through a simple stochastic rule, which makes the method portable, reviewable, and suitable for shared technical environments.

Publications & Reports

Comparing inference methods fairly

Before the formal measurement, generated pseudoexperiments for B → D(→ K⁰KK)h at the statistics of the real dataset. As real-data processing exposed new issues, the team revised priorities and timelines according to their necessity and impact.

The software supported the BESIII–LHCb joint gamma measurement. The papers report approximately 5% lower LHCb statistical uncertainty with the new method compared with a binned analysis of the same datasets. This is a collaborative method result, not a TensorFlow speedup or an individually attributable gain. The final combined result is gamma = 71.3 ± 5.0 degrees, including statistical and systematic uncertainties.

  • Validated the strategy against a higher-yield control decay and monitored yield, width, and fit stability across runs and selection settings.

Result

  • Demonstrated that the extraction logic was robust enough to support a dedicated branching-ratio measurement, which is a stronger validation than simply showing a visible peak.

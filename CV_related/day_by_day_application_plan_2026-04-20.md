## Working assumptions

- Goal: execute the current shortlist as a structured application sprint, not a mass-application campaign.
- Default pace: `1 tailored application per day` for strong-fit roles, then `1 per day` for adjacent/stretch roles.
- Before sending any application, re-check that the posting is still active on the same day.
- For each application, only customize:
  - CV title
  - summary
  - top 6 bullets
- Keep one short application log with:
  - date
  - role
  - version used
  - status
  - next follow-up date

## Daily template

Use this same checklist every day:

1. Re-check live status of the target posting.
2. Copy the base CV version closest to the role.
3. Replace the title, summary, and top 6 bullets using the shortlist guidance.
4. Do one final consistency check:
   - no fake keywords
   - no domain claims you cannot defend
   - first half page clearly says `simulation / validation / physical systems`
5. Submit the application.
6. Log the application and set a follow-up date at `D+7` and `D+14`.
